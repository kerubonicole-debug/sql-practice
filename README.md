SQL Practice: dvdrental

SQL practice queries written against the PostgreSQL dvdrental sample database, using DBeaver.

Part of my move into data analytics and data engineering.

What's covered
- Filtering with `WHERE`, `ORDER BY` and `LIMIT`
- Aggregates (`COUNT`, `SUM`, `AVG`) with `GROUP BY`
- Multi-table `JOIN`s (up to five tables)
- Revenue analysis by film, category, store, city, country and customer
- Grouping by month with `DATE_TRUNC`
